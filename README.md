# Networking & Web Infrastructure

**Holberton School · Software Engineering Coursework**

Networking and infrastructure exercises exploring network protocols, host configuration, ports and the sequence behind loading a web page.

## Technology and concepts

Networking fundamentals, IP addressing, TCP/UDP, Bash and web infrastructure diagrams.

## Modules

| Directory | Focus |
| --- | --- |
| [`basics_0/`](./basics_0/) | OSI model, network types, IP/MAC addresses, TCP/UDP and connectivity. |
| [`basics_1/`](./basics_1/) | Host networking, local addresses and listening ports. |
| [`what_happens_when_your_type_google_com_in_your_browser_and_press_enter/`](./what_happens_when_your_type_google_com_in_your_browser_and_press_enter/) | The browser request lifecycle, including DNS, network connections, web servers and an architecture diagram. |

## Working with the exercises

Review the individual directory README files and exercise source before running or compiling them. Each task may have its own dependencies, test driver, or required inputs; do not assume every file is a standalone program.
